Responsive image slider using Owl Carousel, HTML, CSS and JavaScript.
  # Owl Carousel Image Slider

A responsive image slider created using **HTML, CSS, JavaScript, jQuery, and Owl Carousel**.

## Features

- Responsive image slider
- Next / Previous navigation buttons
- Navigation dots
- Auto sliding
- Multiple images displayed on desktop
- Mobile responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery
- Owl Carousel
